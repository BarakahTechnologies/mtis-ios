# MTIS — Apple-Platform Public Website

This repository hosts the public website for **MTIS (Mechanic Tool Inventory System)**, a private,
on-device tool inventory app for iPhone and iPad. An Android version is planned separately.

Public site: **https://mtis.barakahtechnologies.net/**

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Landing page |
| `privacy.html` | Apple-platform privacy policy |
| `support.html` | Support and FAQ |

Each page also has Spanish and Arabic versions. The checked-in HTML is generated by
`build/generate.py`; edit the generator or `assets/site.css`, then run:

```sh
python3 build/generate.py
```

## Repository and deployment privacy

Keep this GitHub repository **private**. The deployed product website is public, but visitors do
not need access to the source repository.

Deploy it with **Cloudflare Pages**, not GitHub Pages:

1. Import the private `BarakahTechnologies/mtis-ios` repository into Cloudflare Pages.
2. Use production branch `main`, no framework preset, build command `exit 0`, and output directory
   `.`.
3. Confirm the generated `*.pages.dev` address works.
4. In the Pages project's **Custom domains** panel, add `mtis.barakahtechnologies.net`.
5. Let Cloudflare create or replace the DNS record; do not point it to GitHub Pages.

There is intentionally no repository `CNAME` file. Cloudflare Pages stores the custom domain in
the project configuration.

## Platform separation

This site and its privacy policy currently describe the Apple version. When Android launches, add
clearly labeled Android download and privacy links without replacing the Apple-specific policy.

## About MTIS

MTIS tracks tools, photos, serial and stock numbers, warranty and calibration dates, maintenance
history, toolboxes, and inventory value. Data stays on the device. The app has no account, server,
advertising, analytics, or tracking.
